# 采集系统

## 系统概述

末日降临后，所有异兽尸体都会被末日能量浸染，形成「可采集」状态。击杀异兽后，尸体不会自动掉落材料，必须主动采集才能获取资源。采集完成后，尸体被末日能量分解消散。

## 核心规则

### 采集触发
- 异兽死亡后，尸体上方浮现**淡蓝色半透明提示框**：【可采集】
- 只有**安全区认可的同伴**（契约者+星辰）能看到提示
- 非安全区成员无法看到也无法采集
- 尸体在**30分钟内**未采集会自动消散（末日能量分解），材料全部浪费

### 采集流程
1. **靠近**：走到尸体旁边（2米范围内）
2. **触发**：心中默念「采集」或伸手触碰尸体
3. **采集动画**：淡蓝色光纹从尸体表面浮起，材料逐一析出
4. **完成**：尸体化为光点消散，材料落入采集者手中

### 采集产出

每次采集可获得以下材料（根据异兽等级和种类不同）：

| 材料类型 | 获取概率 | 说明 |
|----------|----------|------|
| 兽核 | 100%（必须采集） | 异兽核心，不采集则无法获得 |
| 兽肉 | 80% | 可食用，品质随异兽等级提升 |
| 兽皮 | 60% | 制作装备和建筑的材料 |
| 兽骨 | 40% | 制作武器和加固建筑 |
| 特殊材料 | 10-30% | 高级异兽掉落稀有材料 |

### ⚠️ 兽核必须采集

**重要变更**：兽核不再自动掉落，必须通过采集获得。

- 未采集的尸体 = 0收益（包括兽核）
- 这意味着战斗后必须安全地接近尸体才能获取资源
- 战斗中如果被迫撤退，可能错过采集窗口（30分钟消散）
- 增加了战斗后的风险管理——是否值得冒险回去采集？

## 天赋系统：采集天赋

### 天赋等级

| 等级 | 名称 | 效果 | 获取方式 |
|------|------|------|----------|
| 无天赋 | 普通采集 | 获得**50%**材料（向下取整） | 默认状态 |
| Lv.1 | 初级采集 | 获得**100%**材料 | 击杀100只异兽后自动觉醒 |
| Lv.2 | 中级采集 | 获得**100%材料 + 10%概率双倍** | 击杀500只异兽 |
| Lv.3 | 高级采集 | 获得**100%材料 + 20%概率双倍 + 稀有材料概率+50%** | 击杀2000只异兽 |
| Lv.4 | 大师采集 | 获得**150%材料 + 30%概率双倍 + 稀有材料概率+100%** | 击杀5000只异兽 |
| Lv.5 | 宗师采集 | 获得**200%材料 + 必定双倍兽核 + 解锁隐藏材料** | 击杀10000只异兽 |

### 无天赋惩罚详解

**没有采集天赋的角色**，采集时只能获得基础产出的**50%**：

| 材料 | 基础产出 | 无天赋产出（50%） | 说明 |
|------|---------|-----------------|------|
| 兽核 | 1颗 | **0-1颗**（50%概率获得） | 最痛的削减——可能白打 |
| 兽肉 | 1份 | 0-1份（50%概率） | 食物来源不稳定 |
| 兽皮 | 1张 | 0-1张（50%概率） | 装备材料减半 |
| 兽骨 | 1根 | 0-1根（50%概率） | 武器材料减半 |

> **设计意图**：无天赋角色采集兽核只有50%概率，这意味着两只异兽可能只拿到一颗兽核。这让「谁去采集」成为战术决策——让有天赋的人采集效率翻倍。

### 天赋觉醒条件

采集天赋**不是人人都有**，觉醒条件如下：

- **星辰**：无天赋（前期），通过特殊事件觉醒（首次签订虚空契约时自动觉醒Lv.1）
- **苏瑶**：无天赋（管理型人才，不擅长战斗采集）
- **林小鹿**：无天赋（辅助型人才）
- **顾清寒**：Lv.1 天赋（特种兵，战斗后清理战场经验丰富）
- **沈清音**：无天赋（医生型，专注治疗）
- **叶知秋**：无天赋（技术型）
- **楚月**：Lv.2 天赋（职业杀手，对解剖和取材极为熟练）
- **苏念**：无天赋
- **顾倾城**：无天赋
- **夜星瞳（猫族）**：Lv.1 天赋（猫族本能，对猎物敏感）
- **白月光（狼族）**：Lv.2 天赋（狼族天生猎手，采集效率极高）
- **九尾（狐族）**：Lv.1 天赋
- **棉花糖（兔族）**：无天赋
- **烛龙（龙族）**：Lv.3 天赋（龙族对能量核心有天然感知）

## 后期解锁：一键采集

### 解锁条件

安全区升级到**Lv.5（一阶满级）**后，护罩获得「领域」功能的同时，解锁**一键采集**能力。

### 一键采集规则

| 特性 | 说明 |
|------|------|
| **采集范围** | 护罩覆盖范围内所有可采集尸体 |
| **采集速度** | 瞬间完成（无需靠近尸体） |
| **采集效率** | 按**星辰的天赋等级**计算（Lv.1起步） |
| **材料归属** | 自动存入安全区储藏室 |
| **触发方式** | 星辰心中默念「一键采集」或护罩自动检测 |

### 一键采集的进化

| 安全区等级 | 一键采集能力 |
|-----------|-------------|
| Lv.5（解锁） | 护罩范围内尸体自动采集，效率=星辰天赋 |
| Lv.7（石屋） | 范围扩大到护罩边界外10米 |
| Lv.10（石屋满级） | 范围扩大到护罩边界外30米，效率+50% |
| Lv.15（堡垒满级） | 范围扩大到100米，自动识别最优采集者天赋 |
| Lv.20（庄园满级） | 范围扩大到500米，采集材料自动分类入库 |

### 防御塔联动

当安全区建造**防御塔/瞭望塔**后，防御塔击杀的异兽也纳入一键采集范围：

- **Lv.4+**：瞭望塔击杀的异兽，尸体在塔周围20米内可自动采集
- **Lv.7+**：防御塔自带采集光环，击杀后自动采集并传送回安全区
- **Lv.10+**：所有防御设施击杀的异兽，100%自动采集
