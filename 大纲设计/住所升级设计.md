## 二、神话建筑图纸（隐藏路线）

> 正常升级体系之外的**唯一存在**。

### 获取条件
- **唯一来源**：星辰的SSS级天赋「系统漏洞感知」卡bug获得
- **触发方式**：星辰感知到系统规则中的漏洞，利用漏洞卡出神话图纸
- **不可交易、不可转让、不可复制**

### 图纸描述（系统面板显示）

```
【神话建筑图纸】
品质：？？？
来源：？？？
效果：解锁「???」形态
描述：一张不属于这个世界的图纸。线条优美得近乎神圣，
     每一个细节都超越了这个时代应有的工艺水平。
     ……这图纸不应该出现在这里。
```

### 卡bug机制

```
星辰发现系统漏洞
    ↓
利用漏洞卡出神话图纸
    ↓
系统检测到异常，修复漏洞
    ↓
修复后 → 图纸变成【唯一建筑】（漏洞已修复，再也卡不出第二张）
    ↓
唯一建筑需要稀有材料 → 星辰有漏洞感知，材料"刚好能搞到"
```

### 叙事作用
- **前期**：星辰无意中卡出第一张图纸，以为是系统BUG，兴奋又心虚
- **中期**：系统不断修复漏洞，星辰不断发现新漏洞，和系统"斗智斗勇"
- **后期**：卡出的唯一建筑越来越多，全服独一无二，别人只能羡慕
- **结局**：真相浮现——这些漏洞并非偶然，是观察者层面的"选拔机制"

### 设计要点
- 神话图纸**不影响正常升级路线**，是一条隐藏的"第五层"
- 图纸解锁的建筑形态**超出当前时代的认知**，其他选手看到会震惊
- 图纸数量极少（全书可能只出现2-3张），每张都是剧情高潮
- 每张图纸都是**绝版**——因为漏洞已被修复，永远不会有第二张
- "这图纸不应该出现在这里"= 暗示系统并非自然产物

## 三、豪华感营造设计

### 视觉冲击的三个关键节点

| 节点 | 变化 | 描写重点 |
|------|------|---------|
| **木屋→石屋** | 材质跃升 | 从"摇摇欲坠"到"坚不可摧"的安全感跃升 |
| **石屋→别墅** | 格局跃升 | 从"生存"到"生活"的质变——第一次有花园、泳池、马厩 |
| **庄园→主城** | 规模跃升 | 从"住所"到"领地"的统治感——你不再是一个人，而是一个王 |

### 豪华感描写手法

**1. 面积具象化**
> 不要只写"3000平米"，要写：
> "推开铁艺大门，一条百米长的石板路直通主楼。左侧是玫瑰花园，右侧是露天泳池。主楼三层，每层八个房间。地下室是酒窖，阁楼是观星台。"

**2. 功能具象化**
> 不要只说"有训练场"，要写：
> "训练场铺设了特殊材质的地面，落地无声却坚硬无比。东侧是箭靶区，西侧是格斗台，中间是模拟战场。每天清晨，卫队在这里操练，喊杀声传出十里。"

**3. 对比冲击**
> 升级前后的对比是最强的豪华感：
> "三天前，他还在30平米的小木屋里蜷缩着入睡。现在，他站在6层石塔的了望台上，俯瞰着整个万人区。风吹过他的脸，带着自由的味道。"

**4. 细节堆砌**
> 豪华感 = 细节的数量：
> 地暖、壁炉、水晶吊灯、橡木地板、丝绸窗帘、雕花楼梯、铜质门把手、大理石台面……每一个细节都在告诉读者"这里很贵"。

**5. 他人反应**
> 通过配角的眼睛展示豪华感：
> "当星辰推开别墅大门时，跟在身后的几个队友全都愣住了。'这……这是末日？'有人喃喃道，'这比我末日前住的还好。'"

### 升级合理性设计

| 合理性维度 | 设计要点 |
|-----------|---------|
| **生存需求** | 天灾升级→旧住所扛不住→必须升级 |
| **功能需求** | 需要训练场提升战力→需要仓库储存物资→需要工坊制造装备 |
| **社交需求** | 排行榜前100→需要展示实力→住所是最好的名片 |
| **战略需求** | 区域合并→需要更大的领地容纳更多人→从住所到城池 |
| **资源需求** | 升级需要特定材料→逼迫外出探索→驱动剧情 |

### 升级前置条件设计

| 阶段 | 前置条件示例 |
|------|------------|
| 木屋→石屋 | 击杀100只异兽 + 采集500石料 + 生存30天 |
| 石屋→别墅 | 排行榜前100 + 击杀精英怪 + 特殊图纸 |
| 别墅→庄园 | 区域合并完成 + 统领500人 + 击杀区域BOSS |
| 庄园→主城 | 赛季排名前10 + 击杀天灾级BOSS + 特殊材料 |

## 四、风格随机化设计

**中式风格特征**：
- 飞檐翘角、青瓦白墙
- 四合院布局、回廊连廊
- 假山流水、竹林荷塘
- 木雕窗花、石狮镇宅

**洋楼风格特征**：
- 尖顶塔楼、彩色玻璃
- 哥特式拱门、罗马柱
- 喷泉雕塑、玫瑰花园
- 壁炉书房、旋转楼梯

**随机化机制**：
- 每次升级时随机决定风格（50/50）
- 风格不影响功能，只影响外观描写
- 可以通过特殊道具"风格转换卡"切换
- 后期庄园/主城可以混合两种风格
