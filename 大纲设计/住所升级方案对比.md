# 《末日游戏场》住所升级体系 — 参考方案对比

> 整理时间：2026-05-15 01:35

---

## 方案A：纯线性升级（最常见）

**代表作**：《全民求生:只有我能看到系统提示》《黑夜求生:从每日情报开始》

**设计**：
```
草棚 → 木屋 → 石屋 → 砖房 → 城堡 → ...
每级只有一种选择，按顺序升级
```

| 维度 | 评价 |
|------|------|
| ✅ 优点 | 简单清晰，读者零负担；升级节奏好控制；适合"苟"文节奏 |
| ❌ 缺点 | 所有人路线一样，缺乏差异化；没有选择感；后期容易审美疲劳 |
| 📌 适用 | 前期基础阶段（小木屋→石屋） |

---

## 方案B：分支选择型

**代表作**：《全球末日:庇护所无限升级》（部分）、《率土之滨》

**设计**：
```
共同基础 → 分支选择 → 各自路线
         ├─ 生活线（舒适/经济/外交）
         └─ 战斗线（防御/军事/征服）
```

| 维度 | 评价 |
|------|------|
| ✅ 优点 | 有选择感和差异化；不同玩家有不同玩法；二周目有新鲜感 |
| ❌ 缺点 | 需要设计两套内容，工作量翻倍；选了A就不能体验B，可能有遗憾 |
| 📌 适用 | 分支点之后的中后期阶段 |

**你已采用** ✅ — 生活线和战斗线在石屋之后分支

---

## 方案C：模块拼装型

**代表作**：《辐射:避难所》《冰汽时代》《部落冲突》

**设计**：
```
主体建筑 + 功能模块（自由拼装）
例：主屋 + [训练场] + [工坊] + [仓库] + [花园] + ...
每个模块独立升级
```

| 维度 | 评价 |
|------|------|
| ✅ 优点 | 高度自由，玩家自定义；每个住所都独一无二；增加策略深度 |
| ❌ 缺点 | 设计复杂度高；小说中不好描写（太像游戏说明书）；读者记不住 |
| 📌 适用 | 游戏化较重的作品；适合做"系统面板"描写 |

---

## 方案D：科技树驱动型

**代表作**：《文明系列》《全球末日:庇护所无限升级》

**设计**：
```
解锁科技 → 解锁建筑/升级
例：研究"石工术" → 解锁石屋；研究"冶炼" → 解锁铁门/铁墙
```

| 维度 | 评价 |
|------|------|
| ✅ 优点 | 升级有合理性（不是凭空变出来的）；科技树本身就是剧情线 |
| ❌ 缺点 | 科技树太复杂会拖慢节奏；末日背景下"研究科技"需要合理解释 |
| 📌 适用 | 种田文/建设文；有系统面板的作品 |

**可借鉴**：升级前置条件可以用"解锁图纸/研究技术"来解释合理性

---

## 方案E：等级限制型

**代表作**：《部落冲突》（大本营等级限制一切）

**设计**：
```
核心建筑等级 = 一切的上限
例：庇护所Lv.5 → 所有设施最高只能升到Lv.5
升级庇护所 → 全面解锁
```

| 维度 | 评价 |
|------|------|
| ✅ 优点 | 简单粗暴，升级动力明确；不会出现"偏科"问题 |
| ❌ 缺点 | 太线性，没有策略选择；核心建筑升级=一切，其他建筑只是附属 |
| 📌 适用 | 追求简洁的作品；适合"爽文"节奏 |

---

## 方案F：区域扩张型

**代表作**：《文明系列》《率土之滨》

**设计**：
```
核心区域 → 外围区域 → 更大区域
例：内城 → 外城 → 郊区 → 领地 → 王国
每扩张一个区域，需要占领/建设/防御
```

| 维度 | 评价 |
|------|------|
| ✅ 优点 | 有"开疆拓土"的成就感；区域之间有战略关系（内城安全/外城危险） |
| ❌ 缺点 | 区域管理复杂；小说中描写容易变成"流水账" |
| 📌 适用 | 中后期从"住所"到"领地"的转变 |

**可借鉴**：主城阶段可以用区域扩张来增加层次感

---

## 方案G：稀有图纸/材料驱动型

**代表作**：《全民求生:从小木屋开始》系列、《地窟求生》

**设计**：
```
普通升级：材料够了就能升
特殊升级：需要稀有图纸/材料（击杀BOSS/探索遗迹/开宝箱获得）
例：普通石屋→需要500石料；豪华别墅→需要"别墅图纸"+特殊材料
```

| 维度 | 评价 |
|------|------|
| ✅ 优点 | 稀有材料驱动探索和战斗；升级本身就有"开宝箱"的爽感 |
| ❌ 缺点 | 脸黑的读者体验差（"我怎么刷不到图纸"）；需要设计掉落系统 |
| 📌 适用 | 有探索/战斗驱动的作品 |

**可借鉴**：关键升级节点（如别墅→庄园）需要稀有图纸，增加升级的仪式感

---

## 方案H：社交/人数驱动型

**代表作**：《全球冰封:我打造了末日安全屋》

**设计**：
```
住所规模 = f(人数)
人越多 → 需要更大住所 → 触发升级
例：5人小队→需要别墅；50人势力→需要庄园；500人组织→需要主城
```

| 维度 | 评价 |
|------|------|
| ✅ 优点 | 升级有明确的"人"的动机；住所规模和势力规模挂钩，合理 |
| ❌ 缺点 | 独狼玩家体验差；强迫社交可能劝退部分读者 |
| 📌 适用 | 有团队/势力建设的作品 |

**可借鉴**：中后期升级可以和"领地人口"挂钩——你要建主城，得先有足够的人口

## 方案I：天灾驱动型（被动升级）

**代表作**：《寒流求生:从小木屋开始》《全球冰封》

**设计**：
```
天灾强度 > 当前住所承受力 → 被迫升级
例：极寒天灾→木屋扛不住→必须升级石屋；地震→石屋扛不住→必须升级堡垒
```

| 维度 | 评价 |
|------|------|
| ✅ 优点 | 升级理由最充分（不升级就死）；天灾和住所联动，叙事紧凑 |
| ❌ 缺点 | 被动感强，缺乏主动追求；每次都是"被逼的"，爽感打折 |
| 📌 适用 | 硬核求生文 |

**可借鉴**：作为升级的"底线驱动力"——天灾逼你升级，但你想升级还得主动找材料

---

## 方案J：排行榜/社交展示型

**代表作**：《全民领主》系列

**设计**：
```
住所外观 = 社交名片
排行榜前列 → 住所自动获得"光环效果"
别墅/庄园/主城 → 别人来访时的视觉冲击
```

| 维度 | 评价 |
|------|------|
| ✅ 优点 | 住所升级有社交动力；"炫耀"本身就是爽点 |
| ❌ 缺点 | 过于注重外观，可能忽略功能设计 |
| 📌 适用 | 有社交/竞技元素的作品 |

**可借鉴**：住所外观和排行榜排名挂钩——排名越高，住所自动获得视觉特效

## 我的整合建议

### 建议采用的组合：

**基础驱动力 = I（天灾驱动）+ G（稀有图纸）**
> 天灾逼你升级（不升级就死），但关键节点需要稀有图纸/材料（击杀BOSS/探索获得）

**差异化 = B（分支选择）**
> 已采用 ✅ — 生活线/战斗线

**社交展示 = J（排行展示）+ H（人数驱动）**
> 住所外观和排行榜排名挂钩；中后期升级需要足够的人口

**合理性 = D（科技树）简化版**
> 升级需要"解锁图纸"来解释——不是凭空变出来的

**主城阶段 = F（区域扩张）**
> 主城不再是"住所"，而是"领地"——有内城/外城/郊区/领地之分

### 具体整合示例：

```
Lv.1-5 小木屋：天灾驱动（极寒逼你从30㎡扩到500㎡）
Lv.6-10 石屋：天灾驱动 + 稀有材料（击杀精英怪掉落石料精华）
Lv.11-15 别墅/要塞：分支选择 + 稀有图纸（击杀区域BOSS掉落别墅图纸）
Lv.16-20 庄园/堡垒：人数驱动（统领500人才能建庄园）+ 排行榜前100
Lv.21-25 主城/军事主城：区域扩张 + 赛季排名前10 + 天灾级BOSS掉落
```
