# 末日求生类小说·住所升级体系参考

> 研究日期：2026-05-15
> 用途：为《末日游戏场》住所升级体系设计提供参考

---

## 一、热门作品庇护所升级路线汇总

### 1.1 《全球末日：庇护所无限升级》（晨浩）

**核心机制**：主角路岩觉醒"末日生存系统"，可无限分解制造生存必需品、无限升级庇护所。

**升级路线**：
| 阶段 | 建筑类型 | 面积 | 层数 | 核心功能 |
|------|----------|------|------|----------|
| 初始 | 简易避难所 | ~10㎡ | 1层 | 勉强遮风挡雨 |
| 中期 | 石屋/木石混构 | ~30-50㎡ | 1-2层 | 分区功能（主卧、次卧、仓库、厨房等） |
| 后期 | 小型堡垒 | ~80-150㎡ | 2层+ | 六大区域：主卧室(作战中心)、次卧室、仓库、厨房、卫生间、工坊 |
| 终局 | 大型避难所/据点 | 200㎡+ | 多层 | 防御工事、生产设施、多人居住 |

**设计亮点**：
- 避难所分化出**六个功能区域**：主卧室(作战中心)、次卧室、仓库、厨房、卫生间、工坊
- 升级需要**设计图**，不同设计图决定不同升级方向
- 材料从基础（木材、石料）到高级（金属、特殊材料）逐步解锁
- 系统提示式升级：融入指定材料→触发升级→获得新功能

---

### 1.2 《全民求生：从一个小木屋开始》

**核心机制**：全民穿越求生世界，从零开始建造庇护所，通过采集物资升级。

**升级路线**：
| 阶段 | 建筑类型 | 面积 | 层数 | 核心功能 |
|------|----------|------|------|----------|
| 1级 | 破旧小木屋 | ~6-8㎡ | 1层 | 勉强遮蔽，无额外功能 |
| 2级 | 小木屋（修复） | ~12-15㎡ | 1层 | 基础保暖，可放置小型家具 |
| 3级 | 三级木屋 | ~20-25㎡ | 1层 | 解锁坐标功能、迁徙功能 |
| 4级 | 石木混合屋 | ~30-40㎡ | 2层 | 砖石配比，二楼空间，仓库升级 |
| 5级+ | 石屋/强化建筑 | 50㎡+ | 2层+ | 工作台、烹饪台、更高级设施 |

**具体描写示例（3级石屋）**：
- 面积：约30-40㎡，二层结构
- 附带设施：工作台（可制作品质更高的工具）、木质椅、木质桌、一级仓库、一级烹饪台、木质床、薄被
- 升级条件：需要砖石+石材，建造值达到指定数值

**分支升级**（来自《全民求生：开局获得全知之眼》）：
- **标准路线**：150块木材 → 2级小木屋（获得扩展位）
- **隐藏路线1**：50木材 + 50石材 → 1级石木屋（防御更强）
- **隐藏路线2**：50木材 + 50硬木材 → 1级加固小木屋（耐久更高）

### 1.3 《黑夜求生：从每日情报开始》

**核心机制**：每日情报系统提供信息优势，庇护所分级明确。

**升级路线**：
| 等级 | 建筑类型 | 面积 | 核心属性 | 升级需求 |
|------|----------|------|----------|----------|
| 1级 | 简陋草棚/初始棚屋 | ~4-6㎡ | 极少量保暖，无法抵御怪物 | — |
| 2级 | 木屋 | ~16㎡ | 少量保暖，抵挡普通级黑夜生物 | 100木材 + 100石头 |
| 3级 | 石屋 | ~25-30㎡ | 中等保暖，抵挡较强生物 | 200石材 + 100木材 + 特殊材料 |
| 4级+ | 强化石屋/堡垒 | 40㎡+ | 高防御，多功能区 | 大量高级材料 |

**设计亮点**：
- **数值化描述**：明确给出"占地十六平方米"等具体数值
- **功能与防御挂钩**：每级庇护所能抵御的生物等级不同
- **情报驱动升级**：通过每日情报发现隐藏资源点，加速升级

### 1.4 《全球冰封：我打造了末日安全屋》

**核心机制**：重生+囤物资，末世来临前就开始打造安全屋。

**升级路线**：
| 阶段 | 建筑类型 | 核心特征 |
|------|----------|----------|
| 前期 | 普通住宅改造 | 加固门窗、囤积物资 |
| 中期 | 地下安全屋 | 地下空间扩展、通风系统、独立供电 |
| 后期 | 综合型避难所 | 多层地下结构、自给自足系统、多人容量 |

**设计亮点**：
- **提前布局**：末世前就开始升级，体现"重生者优势"
- **重地下轻地上**：冰封末世主题，地下空间更实用
- **系统化设施**：沼气池、通风系统、独立发电等逐一解锁

---

### 1.5 《末世有套房》/《我在末世有套房》

**核心机制**：随身空间/房产升级系统，从单间到基地的跨越。

**升级路线**：
- 初始：一间普通房间
- 中期：多房间套房，配备基础生活设施
- 后期：独立基地，包含生产、防御、居住多重功能
- 终局：智能化城市概念

---

### 1.6 《末世：我的房子能升级》

**核心机制**：房子本身具有自我升级能力，击杀僵尸获得升级资源。

**升级要素**：
- 警报器（防御感知）
- 连杀奖励系统（击杀激励）
- 房屋自动修复
- 功能区逐步解锁

---

### 1.7 《末世天灾：开局打造蜂巢庇护所》

**核心机制**：蜂巢结构庇护所，模块化扩展。

**设计亮点**：
- 六边形蜂巢结构，空间利用率极高
- 模块化设计：每个蜂室可独立升级
- 从单个蜂室→蜂巢群→蜂巢城的发展路线

## 二、游戏建筑升级系统设计参考

### 2.1 部落冲突（Clash of Clans）

**核心设计**：
- **大本营等级**为核心，限制所有其他建筑的最高等级
- 升级路线：1本→17本（大本营每升一级解锁新建筑、新功能）
- **建筑分支**：
  - 防御建筑：箭塔、加农炮、迫击炮、法师塔、防空火箭、X弩、地狱塔、天鹰火炮
  - 资源建筑：金矿、圣水收集器、暗黑重油钻井、储金罐、圣水瓶、暗黑重油罐
  - 军事建筑：兵营、暗黑兵营、法术工厂、暗黑法术工厂、训练营
  - 城墙：从木墙→石墙→铁墙→...→火焰墙

**升级设计要点**：
- 每级大本营外观明显变化（从简陋木屋→石屋→铁堡→...→高科技堡垒）
- 升级时间随等级指数增长（低级秒升，高级需要数天甚至数周）
- **前置条件**：大本营等级必须达标，否则无法升级其他建筑

### 2.2 率土之滨

**核心设计**：
- **城主府等级**为核心，决定所有建筑上限
- **两大分支**：
  - **军事分支**：兵营、校场、城墙、箭塔等（提升战斗力）
  - **城建分支**：仓库、民居、农田、伐木场等（提升资源产出）
- 分城系统：主城之外可建立分城，分城独立发展
- 建筑满级后激活特殊技能（如仓库满级→税收+1000）

**升级设计要点**：
- 建筑以城主府等级为核心前提
- 军事与城建可并行发展，但资源有限需要取舍
- 声望建筑与普通建筑分开计算

### 2.3 文明系列（Civilization）

**核心设计**：
- 城市发展路线：定居点→村庄→城镇→城市→大都市→特大都市
- 建筑与科技树绑定：需要先研究对应科技才能建造对应建筑
- 奇迹建筑：独特建筑，全球只有一个文明能建造
- 区域系统：圣地、学院、商业区、工业区、剧院广场等

**升级设计要点**：
- 科技/文化进步驱动建筑解锁
- 地形影响建筑效果（山地加成、河流加成等）
- 从"产出"角度衡量建筑价值（生产力、金币、文化、科技等）

### 2.4 英雄无敌系列

**核心设计**：
- 村镇议事堂（1级，基础）→ 城市政务厅（3级，2000金币/天）→ 国会（5级，4000金币/天）
- 建筑有严格的前置关系链
- 不同种族有独特的建筑风格和升级路线

## 三、升级体系设计模式总结

### 3.1 常见升级路线模板

**基础路线（5级制）**：
```
Lv.1 草棚/初始棚屋（4-8㎡）
  ↓ 木材×50
Lv.2 木屋（12-16㎡）
  ↓ 木材×100 + 石材×100
Lv.3 石屋（25-40㎡，可能2层）
  ↓ 石材×300 + 金属材料×50
Lv.4 强化建筑/堡垒（60-100㎡，2-3层）
  ↓ 高级材料×大量
Lv.5 城堡/主城（150㎡+，多层复合结构）
```

**扩展路线（7-10级制）**：
```
Lv.1 草棚 → Lv.2 木屋 → Lv.3 石木混合 → Lv.4 石屋
→ Lv.5 强化石屋 → Lv.6 小型堡垒 → Lv.7 中型堡垒
→ Lv.8 大型堡垒 → Lv.9 城堡 → Lv.10 主城/王城
```

### 3.2 面积增长规律

| 等级 | 典型面积 | 增长倍数 | 说明 |
|------|----------|----------|------|
| Lv.1 | 4-8㎡ | — | 初始，仅容一人蜷缩 |
| Lv.2 | 12-16㎡ | 2-3x | 可放下基本家具 |
| Lv.3 | 25-40㎡ | 2-2.5x | 功能分区开始出现 |
| Lv.4 | 60-100㎡ | 2-2.5x | 多层结构，功能完善 |
| Lv.5 | 150-200㎡ | 2x | 堡垒级别，防御完善 |
| Lv.6 | 300-500㎡ | 2x | 从建筑→据点的跨越 |
| Lv.7+ | 500㎡+ | — | 城池级别，区域化管理 |

**规律**：面积增长约2-3倍/级，后期增速放缓但质量（材质、功能）大幅提升。

### 3.3 功能解锁节奏

| 等级 | 解锁功能 | 功能类型 |
|------|----------|----------|
| Lv.1 | 基础遮蔽、睡眠 | 生存 |
| Lv.2 | 保暖、储物 | 生存+ |
| Lv.3 | 烹饪、工作台、二楼 | 生活 |
| Lv.4 | 独立卧室、仓库、卫生间 | 舒适 |
| Lv.5 | 工坊、防御设施、供暖 | 生产+防御 |
| Lv.6 | 多人居住、农场、发电 | 社区 |
| Lv.7+ | 商业区、军事区、行政区 | 城市 |

## 四、"豪华感营造"设计手法

### 4.1 核心设计原则：对比产生豪华感

**手法一：材质跃升描写**
```
草棚→木屋："那些枯草终于被拆掉了，取而代之的是一根根削得整齐的原木。
             雨水不再从缝隙渗入，风也不再能穿透墙壁。"
木屋→石屋："当最后一块石砖嵌入墙体，他敲了敲墙壁——
             沉闷、厚实、坚不可摧。这不再是那个摇摇欲坠的木棚，
             而是一座真正的房子。"
石屋→别墅："地面上铺着打磨光滑的石板，不再是凹凸不平的泥地。
             墙壁刷着石灰，窗户镶着玻璃——玻璃！
             在末日里，这比黄金还奢侈。"
```

**手法二：空间感对比**
```
升级前："他伸开双臂就能碰到两边的墙壁，转身都要小心翼翼。"
升级后："他站在新房间的正中央，伸开双臂——什么也碰不到。
         这是他第一次在末日里感受到'宽敞'这个词的重量。"
```

**手法三：功能解锁的仪式感**
```
"系统提示音响起的那一刻，他感觉整个世界都在震动。
 光芒从屋顶倾泻而下，墙壁像是有了生命般向外扩展。
 当光芒散去，他发现自己站在一个完全不同的空间里——
 不再是那个只能勉强容身的洞穴，
 而是一个有卧室、有厨房、有工作间的……家。"
```

**手法四：细节堆叠法**
```
"他一间一间地走过去。
 卧室里有一张真正的床——不是铺在地上的草垫，是有床架、有床垫的床。
 厨房里有灶台，有水槽，有储物柜。
 书房里有一张宽大的书桌，桌上放着一盏油灯。
 每走一步，他都觉得自己在做梦。"
```

### 4.2 豪华感描写的五个维度

1. **材质感**：从粗糙到细腻（树皮→木板→石砖→大理石→金属）
2. **空间感**：从逼仄到宽敞（具体面积数字+身体感受对比）
3. **功能性**：从单一到复合（只能睡→能做饭→能工作→能娱乐）
4. **私密性**：从开放到分区（一间通铺→独立卧室→套房）
5. **装饰性**：从素朴到精美（毛坯→粉刷→壁画→吊灯→地毯）

### 4.3 末日背景下的豪华感加成

在末日背景下，以下元素会产生强烈的"豪华感"冲击：
- **玻璃窗**：末日里极其稀缺，比现代世界装落地窗还震撼
- **热水系统**：从冷水到热水的跨越，比面积增加更让人感动
- **照明系统**：从火把→油灯→电灯的升级
- **独立卫生间**：从露天解决到室内冲水马桶
- **供暖系统**：在寒冷末日中，暖气=奢侈
- **隔音效果**：从"听得见外面的风声"到"安静的私人空间"

## 五、升级前置条件的常见设计

### 5.1 材料需求型（最常见）

```
升级条件：
├── 基础材料：木材×N、石材×N、金属×N
├── 稀有材料：特殊矿石、变异兽材料、图纸碎片
└── 货币：金币/资源点×N
```

**设计要点**：
- 低级材料容易获取（砍树、采石）
- 高级材料需要战斗/探索/交易
- 稀有材料制造"卡点"，延长升级周期

### 5.2 等级/属性前置型

```
升级条件：
├── 人物等级 ≥ N
├── 建造技能 ≥ N
├── 已完成特定任务/成就
└── 已解锁特定科技/图纸
```

**设计要点**：
- 防止玩家跳级发展
- 鼓励全面发展而非单一发展
- 与剧情推进挂钩

### 5.3 时间限制型

```
升级条件：
├── 升级耗时：N小时/天
├── 需要在特定时间段内完成（如白天/安全期）
└── 需要连续N天维护/保养才能完成
```

### 5.4 环境/事件驱动型

```
升级条件：
├── 度过特定天灾（如第一次寒潮后解锁保暖升级）
├── 达到特定生存天数
├── 遭遇特定事件后解锁（如第一次怪物潮后解锁防御升级）
└── 季节变化驱动（冬季前必须完成保暖升级）
```

### 5.5 社交/交易型

```
升级条件：
├── 需要与其他玩家交易获取特殊材料
├── 需要组队完成特定副本获取图纸
├── 需要在交易行购买特定道具
└── 声望/好感度达到一定等级
```

## 六、分支系统设计

### 6.1 经典三分支模型

```
基础住所（Lv.1-3 共用）
        │
        ├── 战斗型分支
        │   ├── 偏重防御设施（城墙、箭塔、陷阱）
        │   ├── 偏重武器工坊（锻造台、弹药库）
        │   └── 偏重军事指挥（瞭望塔、信号台）
        │
        ├── 生活型分支
        │   ├── 偏重居住舒适（卧室升级、供暖、热水）
        │   ├── 偏重食物生产（厨房、温室、养殖场）
        │   └── 偏重医疗健康（医疗室、药草园）
        │
        └── 经济型分支
            ├── 偏重资源生产（矿场、伐木场、工厂）
            ├── 偏重贸易交易（商铺、仓库、市场）
            └── 偏重科技研发（实验室、图书馆、工坊）
```

### 6.2 率土之滨的双分支参考

- **军事分支**：兵营→校场→城墙→箭塔→战争工坊
- **城建分支**：农田→伐木场→仓库→民居→市场
- 以"城主府"等级为核心限制，两分支并行但资源有限

### 6.3 复合分支设计（推荐）

```
住所等级
    │
    ├── 核心建筑（必须升级）
    │   └── 主屋/大厅 → 决定其他建筑上限
    │
    ├── 战斗设施（可选升级）
    │   ├── 围墙/栅栏 → 城墙 → 要塞墙
    │   ├── 瞭望台 → 箭塔 → 炮塔
    │   └── 陷阱区 → 迷宫走廊 → 地下暗道
    │
    ├── 生活设施（可选升级）
    │   ├── 简易灶台 → 厨房 → 餐厅
    │   ├── 草铺 → 木床 → 套房
    │   └── 露天厕所 → 简易卫生间 → 独立卫浴
    │
    └── 生产设施（可选升级）
        ├── 手工台 → 工坊 → 工厂
        ├── 小型仓库 → 中型仓库 → 大型仓库
        └── 菜地 → 温室 → 农场
```

## 七、从"建筑"到"城池"的跃升设计

### 7.1 跃升节点设计

```
阶段一：个人庇护所（Lv.1-3）
  特征：单人/双人居住，关注生存
  面积：4-40㎡
  核心矛盾：活下去

阶段二：安全据点（Lv.4-6）
  特征：小型团队，功能完善
  面积：60-300㎡
  核心矛盾：如何舒适地活

阶段三：小型聚落（Lv.7-8）
  特征：10-30人社区，分工协作
  面积：500-2000㎡
  核心矛盾：如何组织管理

阶段四：城镇据点（Lv.9-10）
  特征：100+人，完整社会结构
  面积：2000㎡+
  核心矛盾：如何发展扩张
```

### 7.2 跃升的标志性变化

**从建筑到据点**（Lv.3→Lv.4）：
- 解锁"围墙"功能，住所变成有边界的空间
- 解锁"多人居住"，从独居变为合住
- 解锁"功能分区"，不再是"一间房干所有事"

**从据点到聚落**（Lv.6→Lv.7）：
- 解锁"外部建筑"，住所扩展为建筑群
- 解锁"NPC入驻"，吸引其他幸存者
- 解锁"领地概念"，有明确的势力范围

**从聚落到城镇**（Lv.8→Lv.9）：
- 解锁"城门/城防"，形成完整防御体系
- 解锁"商业区"，形成自给自足的经济循环
- 解锁"行政管理"，建立秩序和规则

### 7.3 跃升的叙事设计

每次跃升应该对应一个**叙事高潮**：
- 第一次跃升：第一次成功抵御怪物潮→"这里不再只是一个睡觉的地方，这是我的堡垒"
- 第二次跃升：第一次收留其他幸存者→"这里不再只是我的家，这是我们的家"
- 第三次跃升：第一次建立贸易路线→"这里不再只是一个聚落，这是一座城"

## 八、针对《末日游戏场》的建议

### 8.1 推荐升级路线

```
Lv.1 破旧木棚（4-6㎡，1层）
    └── 勉强遮蔽，摇摇欲坠，风从四面灌入
    升级条件：木材×30

Lv.2 修补木屋（10-12㎡，1层）
    └── 墙壁密实，有简易门锁，能放下一张草铺
    升级条件：木材×80 + 石材×30

Lv.3 石木混合屋（20-25㎡，1层）
    └── 石基木墙，有简易家具（桌椅、储物箱），独立卧室
    升级条件：木材×150 + 石材×100 + 铁矿×20

Lv.4 石屋（35-45㎡，2层）
    └── 全石结构，二楼卧室，有工作台、灶台、仓库
    升级条件：石材×300 + 铁矿×50 + 玻璃×10（稀缺！）

Lv.5 强化石屋/小型堡垒（60-80㎡，2层）
    └── 围墙+大门，功能分区完善（卧室/厨房/工坊/仓库/卫生间）
    升级条件：石材×500 + 铁矿×100 + 特殊材料×10 + 建造图纸

Lv.6 别墅（120-150㎡，2-3层）
    └── 豪华跃升！玻璃窗、独立卫浴、供暖系统、装饰性家具
    升级条件：大量高级材料 + 稀有图纸 + 生存天数≥30

Lv.7 庄园（250-350㎡，建筑群）
    └── 从单体建筑→建筑群！主屋+工坊+仓库+温室+防御塔
    升级条件：超大量材料 + 特殊事件触发 + 团队协作

Lv.8 小型据点（500-800㎡，含外部建筑）
    └── NPC入驻、围墙扩展、商业雏形、军事设施
    升级条件：领地声望 + 大量资源 + 击退特定入侵事件

Lv.9 城镇（1500㎡+，完整城防）
    └── 城门、城墙、城内分区（居住区/商业区/军事区/行政区）
    升级条件：占领特定地盘 + 科技解锁 + 联盟/势力支持

Lv.10 主城/王城（3000㎡+，城池）
    └── 多层城防、核心建筑群、地标性奇迹建筑
    升级条件：通关特定副本 + 稀世材料 + 全服/全域影响力
```

### 8.2 升级合理性设计

**为什么需要升级？**（紧迫感来源）
1. **天灾递增**：第一波寒潮木屋扛得住，第二波石屋才勉强，第三波必须堡垒
2. **怪物潮**：每N天一次怪物入侵，防御不足则住所受损甚至被毁
3. **功能需求**：想要更好的装备→需要工坊→需要升级住所
4. **社交压力**：其他玩家都在升级，落后=被淘汰
5. **舒适度需求**：寒冷、潮湿、噪音等debuff，升级可消除

**升级的前置条件设计**：
1. **材料阶梯**：基础材料（木材/石材）→中级材料（铁矿/玻璃）→高级材料（合金/特殊矿石）→稀有材料（BOSS掉落/遗迹探索）
2. **图纸系统**：部分高级建筑需要图纸，图纸来自探索/交易/成就
3. **技能要求**：建造技能等级必须达标，技能通过实践提升
4. **生存天数**：某些高级建筑需要生存达到一定天数才能解锁
5. **事件触发**：关键跃升节点需要完成特定事件（如第一次抵御怪物潮后解锁防御建筑）

### 8.3 豪华感营造建议

**每级升级时的描写重点**：

| 升级 | 描写重点 | 情绪关键词 |
|------|----------|------------|
| 1→2 | 墙壁不再漏风，终于有了一扇能关上的门 | 安全感 |
| 2→3 | 石头地面取代了泥地，第一次有了"家具" | 安定感 |
| 3→4 | 有了二楼！站在楼上俯瞰，视野从未如此开阔 | 成就感 |
| 4→5 | 围墙围出了一个院子，这是"我的领地" | 领地感 |
| 5→6 | 玻璃窗、热水、地毯……末日里的五星酒店 | 震撼感 |
| 6→7 | 不再是一栋房子，而是一个庄园！ | 质变感 |
| 7→8 | 有人来了，这里成了他们的家 | 责任感 |
| 8→9 | 城墙拔地而起，城门缓缓关闭——这是一座城 | 王者感 |
| 9→10 | 站在城墙上远眺，这是他亲手建造的王国 | 征服感 |

**关键描写手法**：
1. **升级前后对比**：每次升级都要有"之前的陋室"与"现在的豪宅"的直接对比
2. **五感描写**：不仅写视觉，还要写触感（墙壁的质感）、听感（隔音效果）、嗅感（新木头的香气）
3. **他人视角**：通过其他幸存者的惊叹来衬托住所的豪华
4. **系统面板**：用系统提示的数值变化来强化升级感（面积+XX、新增XX功能、舒适度+XX）
5. **主角心理**：从"能活下来就不错了"到"这是我梦想中的家"的心态转变

### 8.4 分支路线建议

在Lv.5（小型堡垒）时开放分支选择：

```
Lv.5 小型堡垒
    │
    ├── 🗡️ 战斗型路线（偏防御/军事）
    │   → 城墙加厚、陷阱系统、武器工坊、瞭望塔
    │   → 适合：喜欢PVP、怪物潮频繁的玩家
    │   → 升级材料偏重：铁矿、兽骨、战斗类材料
    │
    ├── 🏠 生活型路线（偏舒适/生产）
    │   → 温室、厨房升级、供暖系统、装饰家具
    │   → 适合：种田流、休闲玩家
    │   → 升级材料偏重：木材、布料、植物类材料
    │
    └── 💰 经济型路线（偏贸易/科技）
        → 商铺、仓库扩展、实验室、交易站
        → 适合：商人、科研型玩家
        → 升级材料偏重：金币、图纸、稀有矿物
```

**注意**：分支不是完全互斥的，可以以一个分支为主、其他分支为辅，但主分支升级成本更低、速度更快。

### 8.5 与游戏机制的联动建议

1. **住所等级影响每日收益**：高等级住所提供每日资源产出加成
2. **住所等级影响交易税率**：经济型分支降低交易税
3. **住所等级影响防御战**：战斗型分支在怪物潮中有天然优势
4. **住所等级影响社交**：生活型分支可吸引更多NPC入驻
5. **住所等级影响探索**：某些高级区域需要住所等级达到一定值才能进入

## 九、总结：设计要点清单

- [ ] 设计10级升级路线，每级有明确的面积、层数、功能变化
- [ ] 每级升级有具体的材料需求（基础+稀有）
- [ ] Lv.5开放三分支路线（战斗/生活/经济）
- [ ] 每次升级描写"豪华感"——材质、空间、功能、装饰四维度
- [ ] 升级紧迫感来自天灾递增+怪物潮+功能需求
- [ ] 关键跃升节点（建筑→据点→聚落→城镇）有叙事高潮
- [ ] 系统面板量化展示升级效果（面积+XX、舒适度+XX、防御力+XX）
- [ ] 分支系统允许个性化发展，但保持核心升级路线统一
- [ ] 升级材料从"容易获取"到"需要战斗/探索/交易"逐步提升难度
- [ ] 每次升级前后有强烈的视觉/感受对比描写
