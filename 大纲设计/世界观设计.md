## 一、总纲概述

### 1.1 核心概念

「末日游戏场」是由超越一切文明的至高存在——「观察者」创造的淘汰机制。当宇宙中一片星空的"文明密度"超过阈值，观察者便会选取一颗行星，将其改造为"游戏场"，让行星上的智慧生物在末日环境中互相竞争，最终筛选出"适者"。

本故事讲述的是**第10010号游戏场**——以蓝星（地球）人类为主场的末日竞技场。

### 1.2 故事主线

- **主线一（人类争霸）**：末日降临，人类在游戏场规则下建立据点、争夺资源，前期万人区内部竞争，后期逐步合并为全域争霸。
- **主线二（种族争霸）**：异种族降临，人类不再是唯一的玩家，种族间爆发全面战争。
- **主线三（终极真相）**：揭示游戏场的终极目的——观察者的淘汰计划，星辰面临最终选择。

### 1.3 核心主题

- **生存与选择**：在末日中，人性的光辉与黑暗并存
- **强者为尊 vs 守护弱者**：游戏场规则是优胜劣汰，但星辰的选择是"保护想保护的人"
- **个体 vs 系统**：一个人能否改变整个游戏的规则？

## 二、宏观世界观 —— 「星空淘汰局」

### 2.1 宇宙背景

宇宙不是无限的。资源在消耗，熵在增加，文明在膨胀。当一片星空的"文明密度"超过阈值，星空中就会出现——「观察者」。

**观察者**：超越一切文明的至高存在，没有形体，没有名字，只有意志。它们维护宇宙的"平衡"——当资源消耗过快时，启动「淘汰程序」。

**淘汰方式**：在该星空中随机选取一颗行星，将其改造为"游戏场"，让行星上的智慧生物互相竞争，最终筛选出"适者"。不适者淘汰，适者获得"晋升"资格——进入更高维度的星空。

### 2.2 地球不是第一个

| 编号 | 游戏场 | 物种 | 结果 |
|------|--------|------|------|
| 00001 | 某远古行星 | 硅基生命 | 全灭，无人晋升 |
| 00002 | 某气态行星 | 能量生命 | 1人晋升 |
| ... | ... | ... | ... |
| 10009 | 某海洋行星 | 鱼人文明 | 3人晋升 |
| **10010** | **地球** | **人类** | **进行中** |

### 2.3 观察者的"口味"

观察者不是随机选人的，它们有自己的"审美"：

| 维度 | 说明 |
|------|------|
| **力量** | 不是单纯的武力，而是"解决问题的能力" |
| **智慧** | 不是知识量，而是"应对未知的能力" |
| **意志** | 不是不怕死，而是"在绝望中不放弃" |
| **魅力** | 不是长得好看，而是"能让别人跟随你的能力" |
| **创造力** | 不是重复别人做过的事，而是"打破规则的能力" |

**爽点**：星辰的"贱萌坑货"风格，恰恰是观察者最喜欢的——他总能用意想不到的方式解决问题。

### 2.4 埋线策略（世界观揭秘节奏）

| 阶段 | 揭示内容 | 不揭示的内容 |
|------|---------|-------------|
| **前期（人类争霸）** | 游戏场规则、排名系统、天灾机制 | 观察者的存在、管理员的身份 |
| **中期（种族争霸）** | 异种族降临、种族战争、"系统背后似乎有意志" | 观察者的本质、管理员与观察者的关系 |
| **后期（神明博弈）** | 观察者现身、管理员的真相、晋升的选择 | 最终选择题的答案（留给星辰自己决定） |

**前期暗示方式**：
- 系统偶尔出现"无法解释"的行为（安全区不在系统规则内，系统却不管它）
- 某些遗迹/古老文字暗示"这不是第一次"
- 星辰偶尔感觉"有人在看我"，但找不到来源

## 三、游戏场系统 —— 「第10010号游戏场」

### 3.1 系统降临

末日不是天灾，而是系统降临。全球78亿人同时看到天空出现巨大的金色文字：

```
「第10010号游戏场 · 启动」
「参赛者：78亿」
「年龄范围：18-65岁」
「规则：生存」
「目标：成为最后的幸存者」
「奖励：晋升」
「惩罚：淘汰（死亡）」
「新手保护期：3天」
「祝你好运。」
```

然后，所有人被强制传送到随机地点，每人获得一间小木屋。

### 3.2 系统面板

每个参赛者获得一个系统面板：

```
┌─────────────────────────────────┐
│  【第10010号游戏场 · 个人面板】   │
│                                 │
│  姓名：星辰                      │
│  年龄：22                        │
│  等级：Lv.1                      │
│  经验：0/100                     │
│                                 │
│  ┌─ 基础属性 ─┐                  │
│  │ 力量：10   │                  │
│  │ 体质：10   │                  │
│  │ 精神：10   │                  │
│  │ 敏捷：10   │                  │
│  └───────────┘                  │
│                                 │
│  天赋：【？？？】未觉醒           │
│  技能：无                        │
│                                 │
│  背包：[ 空 ]                    │
│  据点：[ 未建立 ]                 │
└─────────────────────────────────┘
```

**属性说明**：
- **力量**：物理攻击力、负重能力
- **体质**：生命值、耐久、恢复速度
- **精神**：感知力、精神抗性、特殊能力基础
- **敏捷**：速度、反应、闪避

**隐藏属性**（不显示，但影响运算）：
- **魅力**：影响他人、谈判、领导力、NPC好感度
- **幸运**：影响暴击率、掉落率、随机事件走向

### 3.3 排名系统

#### 开启条件
- 新手期（前3天）不显示排名
- 第4天起开启区域排名

#### 排行榜类型

| 排行榜 | 计算方式 | 权重 |
|--------|---------|------|
| **综合榜** | 生存质量 + 战力 + 据点 + 贡献 | 100% |
| **击杀榜** | 击杀异兽数量 × 异兽等级 | — |
| **据点榜** | 据点等级 × 人口 × 防御力 × 繁荣度 | — |

#### 显示规则
- **只显示前100名**（名字 + 排名，不显示具体数值）
- 自己的排名单独显示（"你的排名：第X名"）
- 不显示和前一名的差距
- 合并后排行榜**清零重算**
- 上一赛季前100名有**特殊标记**（荣誉感）

#### 战力算法

战力不是直接属性，而是系统根据多维度计算的综合值：

```
战力值 = (力量×1.2 + 体质×1.0 + 敏捷×1.1 + 精神×0.8) 
        × 等级系数 
        × 天赋系数 
        × 装备加成 
        × 技能加成 
        × 战绩修正
```

战力值不直接显示，只显示**排名区间**：前90%/前50%/前10%/前1%/前0.1%/前0.01%

## 五、天灾系统

### 5.1 天灾周期

- **灾期**：21天，天灾持续
- **休整期**：7天，天灾暂停，可交易、建设、社交、备战
- **总周期**：28天一循环

### 5.2 天灾类型（写实版）

| 天灾 | 描述 | 影响 |
|------|------|------|
| ❄️ **极寒** | 温度骤降至-40°C以下 | 暴露即死，水源冻结，取暖是核心生存问题 |
| 🔥 **极热** | 温度飙升至50°C以上 | 中暑脱水，食物腐烂加速，水源蒸发 |
| 🌪️ **沙尘暴** | 能见度为零的沙尘席卷 | 迷路、呼吸困难、建筑被掩埋 |
| 🌊 **暴雨洪涝** | 连续暴雨，水位暴涨 | 低洼地带被淹，物资被冲走 |
| 💨 **台风/飓风** | 12级以上大风 | 建筑被摧毁，物资被卷走 |
| ⚡ **雷暴** | 持续雷击，金属和高处危险 | 金属装备/武器引雷，露天即死 |
| 🌫️ **浓雾** | 能见度极低的浓雾 | 视野受限，异兽偷袭，迷路 |
| 🏜️ **干旱** | 长期无降水，水源枯竭 | 饮水危机，作物枯死 |
| 🪨 **地震** | 大规模地震，地形改变 | 建筑倒塌，道路断裂 |
| 🌋 **火山灰** | 远处火山喷发，火山灰覆盖 | 空气质量极差，阳光被遮挡 |

### 5.3 天灾与地形关联

每个区抽到的天灾不同，取决于地形：

| 地形 | 常见天灾 |
|------|---------|
| 山区 | 极寒、地震 |
| 沙漠 | 极热、沙尘暴、干旱 |
| 沿海 | 暴雨洪涝、台风 |
| 平原 | 暴雨洪涝、雷暴 |
| 森林 | 浓雾、暴雨 |
| 工业区 | 雷暴、浓雾 |

### 5.4 天灾升级机制

| 循环次数 | 天灾等级 | 描述 |
|---------|---------|------|
| 第1循环 | Ⅰ级 | 小灾，局部影响 |
| 第2循环 | Ⅱ级 | 中灾，大范围影响 |
| 第3循环 | Ⅲ级 | 大灾，全域影响 |
| 第4循环 | Ⅳ级 | 灾厄，生存率骤降 |
| 第5循环+ | Ⅴ级 | 终焉级，只有最强者能活 |

### 6.3 安全区（主角金手指）

## 七、区域合并机制

### 7.1 合并节奏

| 阶段 | 时间 | 区域规模 | 触发条件 |
|------|------|---------|---------|
| **新手期** | 第1-3天 | 万人区 | 系统强制分配 |
| **第一次合并** | 第1次休整期 | 十万人区 | 第1循环天灾结束 |
| **第二次合并** | 第2次休整期 | 百万人区 | 第2循环天灾结束 |
| **第三次合并** | 第3次休整期 | 千万人区 | 第3循环天灾结束 |
| **第四次合并** | 第4次休整期 | 亿人区 | 第4循环天灾结束 |
| **全域开放** | 第5次休整期 | 全球 | 第5循环天灾结束 |

### 7.2 合并时发生什么

| 事件 | 效果 |
|------|------|
| **区域重叠** | 两个区的地图重叠，边界消失 |
| **据点碰撞** | 两个区的据点开始接触 |
| **排名重算** | 合并后排名重新计算，大洗牌 |
| **天灾升级** | 合并后天灾等级+1 |
| **新资源点** | 合并区域交界处出现稀有资源点 |

### 7.3 合并时机

合并不在天灾期间发生，而是在**休整期的最后一天**：

```
Day 21：天灾结束
Day 22-27：休整期（交易、建设、备战）
Day 28：休整期最后一天 → 系统公告合并 → 新区域地图生成
Day 29：新赛季开始，新天灾降临
```
