## 八、住所升级体系

### 基础阶段（单线）

**小木屋（单层）**：30 → 60 → 120 → 240 → 500㎡

**石屋（多层）**：500(3层) → 800(3层) → 800(6层) → 1000(6层) → 1500(地下3+地上6)㎡

### 分支点：石屋 Lv.10 之后选择发展方向

**生活分支**（别墅 → 庄园 → 主城）：
- 别墅：3,000 → 6,000 → 15,000 → 50,000 → 100,000㎡
- 庄园：200,000 → 500,000 → 1,000,000 → 5,000,000 → 10,000,000㎡
- 主城：50 → 500 → 3,000 → 6,000 → 10,000 k㎡

**战斗分支**（要塞 → 堡垒 → 军事主城）：
- 军事要塞：3,000 → 6,000 → 15,000 → 50,000 → 100,000㎡
- 战争堡垒：200,000 → 500,000 → 1,000,000 → 5,000,000 → 10,000,000㎡
- 军事主城：50 → 500 → 3,000 → 6,000 → 10,000 k㎡

### 风格随机化
- 中式/洋楼每次升级随机决定（50/50）
- 风格不影响功能，只影响外观描写
- 后期庄园/主城可混合两种风格

### 神话建筑图纸（隐藏路线）
- **唯一来源**：星辰天赋「系统漏洞感知」卡bug获得
- **不可交易、不可转让、不可复制**
- 卡bug机制：发现漏洞 → 卡出图纸 → 系统修复 → 图纸变成唯一（绝版）
- 全书预计出现 2-3 张，每张都是剧情高潮
- 图纸描述："……这图纸不应该出现在这里。"
